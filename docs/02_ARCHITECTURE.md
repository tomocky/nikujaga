# 02. システムアーキテクチャ設計書 (Architecture & Dependency Graph)

## 目的
完成までの全体像と、各モジュール間の依存関係（Dependency）を定義します。

## ディレクトリ構造と依存関係ツリー

```text
/docs             # 各種定義書・仕様書
/src/build        # メインビルドプロセス（調理工程・盛り付け）
/dependencies     # 材料の調達・生成ロジック
  ├── /seasonings # 調味料（塩、醤油、砂糖）
  ├── /vegetables # 野菜（じゃがいも、人参、玉ねぎ）
  └── /meats      # 肉類（牛、豚）
/infrastructure   # 調理器具・ハードウェアの構築ロジック
  ├── /tools      # 刃物（斧、包丁）、ハンマー
  ├── /containers # 鍋（土器）、木樽
  └── /energy     # 炉、木炭、薪
```

## 実行スケジュール（非同期処理の考慮）
本プロジェクトは、完了までに数年単位のリアルの時間を要します。以下のプロセスは並行（非同期）で実行する必要があります。
1. **長期プロセス:** 牛の飼育（約2年）、醤油の発酵（約1年）。
2. **中期プロセス:** じゃがいも等の野菜の栽培（約3〜6ヶ月）。
3. **短期プロセス:** 炉の構築、土器の焼成、鉄の製錬・鍛造（数日〜数週間）。
