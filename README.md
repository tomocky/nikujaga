# プロジェクト概要: Open-Nikujaga (フルスクラッチ肉じゃが構築プロジェクト)

## ミッション
本プロジェクトは、料理「肉じゃが」を既製品に一切依存せず、自然界の基本要素（Earth API）からフルスクラッチでビルド・デプロイするためのOSSプロジェクトです。
材料、調理器具、食器、調理工程など、必要なもの全てにおいて根を深く掘り進める形で細分化し、参加者全員でその解像度を上げていくことを目的とします。

## コア・ルール（限界設定と制約）
1. **Earth APIの原則:**
   - 物理法則、化学反応、未加工の鉱物（鉄鉱石、粘土、海水）、野生の原種（植物・微生物・動物のDNA）のみを初期リソースとして許可する。
   - 例: 「包丁」を直接呼び出すことは不可。「鉄鉱石」から「製錬」「鍛造」のプロセスを経てビルドしなければならない。
2. **階層化されたアーキテクチャ:**
   - レイヤー1: インフラ・ハードウェア構築（炉、土器、刃物）
   - レイヤー2: サブモジュール生成（塩、醤油、農業、畜産）
   - レイヤー3: メインビルドロジック（肉じゃがの調理・加熱プロセス）
3. **トーン＆マナー:**
   - 表現は常に技術的、論理的、かつソフトウェア開発のメタファー（ビルド、依存関係、パッチ、デバッグなど）を使用すること。
   - 真面目なエンジニアリングの文脈で「途方もない手作り（面白狂気）」を大真面目に追求すること。
   - プログラミング言語の疑似コードは極力避け、自然言語（文章）で詳細なプロセスを記述すること。
